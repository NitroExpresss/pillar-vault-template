# 🏛️ Pillar Vault

**Хранилище знаний, которым управляет ИИ-агент, с приборной панелью вместо списка файлов.**

> Это стартовый каркас: клонируй, разверни по [`deploy/DEPLOY.md`](deploy/DEPLOY.md),
> заведи пароль и введи ключ ИИ — дальше хранилище твоё.

Карточки — обычные markdown-файлы в git. Сервер на Go собирает из них модель,
рисует страницы и держит границу доступа: карточки не покидают сервер без
пароля. Публичной части нет — без сессии в браузер уходит только форма входа.

Страницы собираются на сервере. В браузере нет ни копии хранилища, ни поиска
по нему, ни разбора markdown: приходит готовый HTML, а скрипт остаётся лишь
там, где без него нельзя, — холст графа, перестановка панелей, карусель.

```
хранилище (.md)  →  сервер (Go)  →  готовая страница
   карточки          модель,           дашборд, поиск,
   в git             разметка,         граф, правка
                     сессии, доступ
```

## Быстрый старт

Нужен только [Go](https://go.dev/dl/) и git: собранное приложение берётся из
ветки `web-dist`, Node для запуска не нужен.

```bash
mkdir -p viewer/x && git fetch -q origin web-dist && git archive origin/web-dist | tar -x -C viewer/x
go run ./server -root .            # сервер на :8080, индекс соберётся сам
```

Открой `http://localhost:8080` — увидишь форму входа: без пароля хранилище закрыто.

Чтобы войти в админский режим, заведи пароль (не короче 8 символов):

```bash
go run ./server -root . -hash > server/.passhash    # ввести пароль, Enter
go run ./server -root . -check                      # проверить, что записалось
go run ./server -root .                             # перезапустить — замок включён
```

Без сессии сервер показывает только форму ключа — за ней пусто. Верный
пароль — сессия на 7 дней (продлевается, пока пользуешься), и дальше открывается дашборд.

> `server/.passhash` в репозиторий не попадает. Меняешь пароль — перезапуск не нужен:
> сервер следит за файлом и подхватывает новый хэш сам. С сайта — страница «Доступ» (🔑).

### На сервере

Служба systemd на `127.0.0.1:8080`, снаружи nginx с TLS. Docker снят
2026-09-09: сборка образа на одноядерном VDS занимала минуты, а изоляцию
контейнера systemd повторяет директивами `Protect*` в юните.

```bash
sudo systemctl status pillar-vault      # жив ли контур
journalctl -u pillar-vault -f           # что он говорит
bash deploy/passwd.sh                   # сменить пароль
```

Порядок настройки с нуля — [`deploy/DEPLOY.md`](deploy/DEPLOY.md).

## Границы доступа

Три уровня, от слабого к настоящему:

| Уровень | Что делает | Чего стоит |
|---|---|---|
| Пароль на сервере | страницы собираются только по сессии, остальным — форма входа | настоящий замок, из браузера не обойти |
| Данных в браузере нет | в HTML уходит только запрошенная страница; копии хранилища на клиенте не существует | нечему утечь из консоли или кэша |

Пароль хранится хэшем PBKDF2-HMAC-SHA256 (600 000 итераций, случайная соль),
сверка в постоянном времени, сессия в HttpOnly-куке на 7 дней с продлением раз в сутки при работе, 10 попыток входа
за 15 минут с адреса. Подробности — [`server/README.md`](server/README.md).

## Карточка

Одна сущность — один файл. Frontmatter обязателен:

```yaml
---
type: supplement        # fact | supplement | guide | hypothesis | concept | pillar
                        # source | note | question | area | plan | goal | task | archive
summary: "Одна строка: о чём карточка. По ней находят, не открывая файл."
tags: [здоровье/добавки, детокс]
status: draft           # draft | researching | complete | archived
---
```

`summary` пишется всегда — карточка без него для поиска не существует.
Первый тег таксономический, ровно один из дерева: `здоровье`, `здоровье/добавки`,
`здоровье/практики`, `бизнес`, `бизнес/it`, `бизнес/project-mapping`, `pkm`,
`дела`, `цели`. Остальные — свободные. Ветка ищется префиксом.

Индексных файлов нет: хранилище само себе индекс и не может разойтись с реальностью.

```bash
rg -l 'tags:.*здоровье' -g '*.md' .     # что есть по теме (вся ветка)
rg -N -o '^summary:.*' -g '*.md' facts  # каталог раздела
```

## Интерфейс

Личный сад и командный центр — приложение на React в [`web/`](web/)
(Vite + TypeScript), стиль «Рассвет над кодом»: небо по времени суток,
мягкое солнце, тонкий дождь матрицы и стеклянные виджеты. Сервер на Go
остаётся моделью, границей доступа и API; формы — те же обработчики, ответ
JSON-ом по заголовку `X-Pillar-Api`. Сам Go рисует только форму входа.

- **Сад** — нерушимые столпы растениями (с главной пока скрыт, код на месте).
- **Сегодня** — дела на день: закрыть (в исходной карточке), убрать из дня,
  выбрать из всех дел или вписать новое.
- **Важное** — закреплённые карточки (`pin: true` во frontmatter): кнопка
  «Закрепить в важном» на карточке, крестик — открепить. Есть и на рабочем столе Android.
- **Что горит, Календарь, Дневник, Тело, Колесо баланса, Учёт дел, Покупки,
  Витрина** — те же данные, что у виджетов Android, одним ответом `/api/board`.
- **Карточка** — разметка, связи в обе стороны, правка на месте; редактор не
  затирает внешнюю правку (конфликт показывает обе версии).
- **Поиск, разделы, темы, «Доступ»** — экраны приложения; адреса
  (`/doc/…`, `/folder/…`, `/tag/…`, `/search`, `/access`).
- **ИИ** — чат с моделью. Без ключа вкладка «ИИ» показывает мастер настройки:
  выбираешь провайдера (рекомендуем Groq — бесплатный ключ на console.groq.com),
  вводишь ключ, сервер проверяет его живым запросом и только потом сохраняет.
- **Подключения** — провайдеры моделей (Grok, OpenAI-совместимые, локальный
  шлюз): экран «Подключения», ключи на сервере в
  `server/.connections.json` (0600, вне git), проверка ключа и запрос к модели.
- **Телефон** — вёрстка под узкий экран; Android-обёртка — [`android/`](android/README.md).

Витрина ориентиров — [`viewer/gallery/`](viewer/gallery/README.md).

```bash
go run ./server -root . -addr 127.0.0.1:8642   # API и вход
cd web && npm ci && npm run dev                # приложение с горячей перезагрузкой
npm run build && rm -rf ../viewer/x && cp -r dist ../viewer/x   # как на сервере
```

На VDS Node не нужен: CI (`.github/workflows/web.yml`) собирает приложение в
ветку `web-dist`, `deploy.sh` раскладывает её в `viewer/x/`, откуда его
отдаёт Go — с корня и только по сессии.

## Структура

| Папка | Содержание |
|---|---|
| `SOUL.md` | Устав хранилища: формат карточек, поиск, теги, протокол необратимых операций |
| `AGENTS.md` · `CLAUDE.md` | Точка входа для подключённого агента |
| `_sys/` | Шаблоны, линтер, служебные скрипты |
| `inbox/` | Точка входа, сырьё до сортировки |
| `pillars/` | Фундамент: цели на жизнь, нерушимое |
| `tasks/` | Бэклог, день, покупки |
| `notes/` | Обработанные записи, замеры |
| `server/` | Бэкенд на Go: индексатор, сессии, доступ |
| `gateway/` | Локальный шлюз к моделям (опционально) |
| `web/` | Приложение на React: исходники интерфейса |
| `viewer/` | Собранный интерфейс — статика, которую отдаёт сервер |
| `android/` | Android-обёртка над вебом |
| `deploy/` | Конфиги для VDS |

Папки заводятся, когда появляется первая карточка. Пустых каталогов «на будущее» не держим.

**Поток данных:** `вход → inbox → вопросы/гипотезы/заметки → проверка → факты/концепции/столпы → архив`

| Пара | Граница |
|---|---|
| столпы / концепции | Концепция → проверка временем → столп |
| факты / источники | Факт — сухой остаток, источник — контекст ссылки |
| вопросы / гипотезы | Вопрос → гипотеза → проверка → факт или архив |
| inbox / заметки | Inbox — сырьё, заметки — обработанное |

## Команды

```bash
go run ./server -root .                  # сервер: индекс, доступ, интерфейс
go run ./server -root . -lint            # линтер: ссылки, edges, теги, summary
go run ./server -root . -hash            # хэш пароля
go run ./server -root . -check           # сверить пароль с настроенным хэшем
bash deploy/passwd.sh                    # сменить пароль на сервере
```

Сервер сам пересобирает модель: при старте, после правки через веб и при
изменении файлов на диске — внешние правки и `git pull` подхватываются за секунды.
Модель живёт в памяти процесса: на диск она не ложится и пересобирать её
руками нечем и незачем.

**Перед коммитом — `go run ./server -root . -lint`. Ошибки чинятся до пуша.**
