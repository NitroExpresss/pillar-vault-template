# 🏛️ Pillar Vault

Личное хранилище знаний под замком: карточки — обычные markdown-файлы в git,
сервер на Go собирает из них модель и отдаёт готовые страницы. Без сессии
в браузер уходит только форма входа.

```
 карточки (.md)          сервер (Go)             браузер
┌──────────────┐   ┌─────────────────────┐   ┌───────────────┐
│  git-репо    │──▶│ модель · доступ ·   │──▶│ готовый HTML  │
└──────────────┘   │ сессии · API        │   └───────────────┘
                   └─────────────────────┘
```

> **Это стартовый каркас.** Клонируй, разверни по [deploy/DEPLOY.md](deploy/DEPLOY.md),
> заведи пароль и введи ключ ИИ — вкладка «ИИ» сама предложит.

## Возможности

- **ИИ** — чат с моделью; без ключа вкладка «ИИ» открывает мастер настройки
  (Groq, Grok, OpenAI-совместимые, локальный шлюз), ключ проверяется живым запросом
- **Сегодня · Важное · Дневник · Тело · Покупки** — виджеты из тех же карточек
- **Граф связей, поиск, темы** — навигация по всему хранилищу
- **Android** — обёртка с виджетами на рабочий стол
- **Замок** — PBKDF2 (600 000 итераций), сессия 7 дней, 10 попыток входа за 15 минут

## Быстрый старт

```bash
mkdir -p viewer/x
git fetch -q origin web-dist && git archive origin/web-dist | tar -x -C viewer/x
go run ./server -root .                           # http://localhost:8080
go run ./server -root . -hash > server/.passhash  # завести пароль
```

Node не нужен: собранный фронт приезжает веткой `web-dist` из CI.

## Карточка

Одна сущность — один файл, frontmatter обязателен:

```yaml
---
type: note      # fact | guide | hypothesis | concept | pillar | task | goal | …
summary: "Одна строка: о чём карточка — по ней находят, не открывая"
tags: [pkm]     # первый тег — из дерева таксономии (SOUL.md)
status: active  # draft | researching | complete | archived
---
```

Перед коммитом: `go run ./server -root . -lint` — ошибки чинятся до пуша.

## Структура

```
inbox/     сырьё до сортировки       server/    бэкенд на Go
pillars/   цели и нерушимое          gateway/   локальный шлюз к моделям
tasks/     дела, день, покупки       web/       React-приложение
notes/     записи и замеры           android/   Android-обёртка
                                     deploy/    VDS: systemd, nginx
SOUL.md    устав хранилища
AGENTS.md  точка входа для ИИ-агента
```

Свои разделы заводятся, когда появляется первая карточка.
