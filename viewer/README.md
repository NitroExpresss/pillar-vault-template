# 🏛️ Pillar Vault Viewer

Всё, что сервер отдаёт браузеру сам: форма входа, шрифты для неё, витрина
ориентиров и место, куда кладётся собранное приложение. Интерфейс — React-
приложение в [`web/`](../web/); границу доступа держит сервер —
[`server/`](../server/README.md): без сессии наружу уходит только форма входа.

История: до 2026-09-10 здесь жило приложение, получавшее всё хранилище одним
куском; потом — страницы на шаблонах Go с островами скриптов; с 2026-10-21
(этап 5.3) — React с API, а от шаблонов остался один замок.

## Как открыть

**Просто:** двойной клик по **`Открыть-хранилище.cmd`** — достанет собранное
приложение (если его ещё нет), поднимет сервер и откроет интерфейс.
(Требуются [Go](https://go.dev/dl/) и git.)

**Вручную:**

```sh
mkdir -p viewer/x && git fetch -q origin web-dist && git archive origin/web-dist | tar -x -C viewer/x
go run ./server -root .                 # сервер на :8080, модель соберётся сама
```

Модель хранилища пересобирается сама: при старте, после правки через веб и при
изменении карточек на диске (агентом, редактором, `git pull`). Шаблон замка
перечитывается так же.

## Файлы

| Файл | Назначение |
|---|---|
| `templates/lock.html` | Форма входа — единственная страница, которую рисует Go |
| `gate.css` / `gate.js` | Небо, солнце и дождь матрицы за формой входа; символы вместо ключа |
| `fonts.css` / `fonts/` | JetBrains Mono для замка локально (OFL 1.1) |
| `gallery/` | Витрина ориентиров — см. `gallery/README.md` |
| `x/` | Собранное приложение (ветка `web-dist`), в git не хранится |
| `Открыть-хранилище.cmd` | Запуск на Windows |
