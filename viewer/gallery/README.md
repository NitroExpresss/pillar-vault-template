# Витрина ориентиров

Карусель на главной странице viewer. Здесь лежат картинки и `config.json`.

## Заменить моки своими фото

**С сайта (и с телефона):** под слайдами на дашборде — «Фото витрины».
Выбрать слайд или «+ новый», приложить фото (JPEG, PNG, WebP, GIF; большие браузер ужмёт до 2000 px),
поправить подписи — «Сохранить». Фото ложится сюда как `photo-<время>.<ext>`,
`config.json` правится сам, всё уходит в git автокоммитом. Прежнее фото слайда
удаляется, если его загружали с сайта или это мок; файлы, положенные руками
под другими именами, сервер не трогает.

**Убрать слайд:** ✕ в углу слайда — первое нажатие спрашивает «Убрать?»,
второе убирает. Все моки разом — «Убрать примеры (N)» в «Фото витрины».
Файл слайда удаляется вместе с ним, если на него не ссылается другой слайд;
удалённый мок можно вернуть из git.

**Руками:**

1. Скинуть файлы в эту папку (`.jpg`, `.png`, `.webp`, `.svg` — что угодно).
2. Прописать их в `config.json` → массив `slides`.
3. Мок-файлы `mock-*.svg` удалить.

```json
{
  "title": "Витрина ориентиров",
  "note": "",
  "autoplayMs": 6000,
  "slides": [
    { "src": "gallery/фото.jpg", "caption": "Заголовок", "sub": "подпись мельче" }
  ]
}
```

Путь в `src` — от корня viewer, поэтому с префиксом `gallery/`.
`autoplayMs` не задан — слайды листаются раз в 7 секунд, `0` — только руками.
`caption` и `sub` необязательны.

## Приватность

Сад закрыт целиком: публичного среза нет, поля `public:` не существует.
Галерея — обычная статика внутри `viewer/`, а туда гостя не пускают: сервер
отдаёт без сессии только четыре файла формы входа, шрифты и вендоров
(`isGateAsset` в `server/main.go`). Новый файл рядом с интерфейсом по
умолчанию приватен — чтобы стать публичным, его пришлось бы вписать в тот
список руками.
